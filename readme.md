# DOA Estimation using Cycle-based ADMM-Net for Fast High-Resolution DOA Estimation

Introduction: We consider a method similar to TLISTA to establish CADMM-Net and CHADMM-Net, respectively denoted as CADMM-Net and CHADMM-Net. These two deep neural networks construct ADMM-Net in a structured manner by utilizing the closure of the set of cyclic matrices and the cyclic matrix along with the Hermitian matrix. ADMM-Net is a deep expansion network based on ADMM. CADMM-Net and CHADMM-Net require learnable vectors per layer with N parameters and N/2 + 1 parameters, respectively, while ADMM-Net requires N2 parameters. By using Fast Fourier Transform (FFT) and Inverse Fast Fourier Transform (IFFT), the computational cost per layer for CADMM-Net and CHADMM-Net reduces to 2N log(N) compared to N2 for ADMM-Net. The main contributions of this work are summarized as follows:
·We introduce two neural networks named CADMM-Net and CHADMM-Net, which are based on the structured deep expansion of ADMM, utilizing cyclic matrices and Hermitian cyclic matrices, respectively.
·We study the performance of these networks under uniform linear array (ESTA) and sparse linear array (SLA) settings for ISTA, ADMM, and LISTA, ADMM-Net, TLISTA, and THLISTA. The proposed models outperform other deep expansion architectures in terms of detection rate, root mean square error (RMSE), and normalized mean square error reconstruction vector (NMSE). They also have lower computational complexity per layer and memory usage.
Conclusions We propose two deep-learning versions of ADMM, CADMM-Net and CHADMM-Net, which impose cyclic and Hermitian cycle constraints on the learnable matrices, thus significantly reducing the number of learnable parameters per layer and lowering computational complexity. Compared with LISTA, ADMM-Net, TLISTA, THLISTA, ISTA, and ADMM, they achieve higher detection rates, RMSE, and NMSE.
